# Approximate tool-definition token count: turbofig vs figma-console-mcp

Date: 2026-10-07T20:17:25Z

**Approximate.** Claude's tokenizer is not public. These counts use two
OpenAI tokenizers as a proxy. They are not a real Claude session count. A
real Claude session count comes from the full benchmark (`bench/agent.ts`).

## Method

1. Get the exact `tools/list` response from each server with
   `bench/mcp-stdio-probe.mjs`, using its `--dump-tools <path>` flag to
   write `JSON.stringify(tools)` to a file. This is the same exact-byte
   data as `session-cost-20261007-144824.md`.
2. Count tokens of that JSON text with `js-tiktoken` 1.0.21
   (`getEncoding("o200k_base")` and `getEncoding("cl100k_base")`),
   installed into a throwaway scratch directory (not added to the repo's
   `package.json`).
3. Divide by a 200,000-token context window for the share figure.

## Commands

```sh
node bench/mcp-stdio-probe.mjs turbofig mcp -- --timeout-ms 15000 \
  --dump-tools /path/to/turbofig-tools.json

node bench/mcp-stdio-probe.mjs npx -y figma-console-mcp@latest -- \
  --env FIGMA_ACCESS_TOKEN=figd_dummy --timeout-ms 45000 \
  --dump-tools /path/to/figma-console-mcp-tools.json

node count.mjs /path/to/turbofig-tools.json
node count.mjs /path/to/figma-console-mcp-tools.json
```

Where `count.mjs` reads the file, runs both encodings with `js-tiktoken`,
and prints the token counts. `figd_dummy` is a placeholder, not a real
token: figma-console-mcp lists its tools without a valid one.
