# Startup time and tool-definition size: turbofig vs figma-console-mcp

Date: 2026-10-07T14:48:24Z
Machine: macOS 15.8 (24H23), arm64
Versions: `figma-console-mcp` 1.40.9, `turbofig` 0.1.0 (`turbofig mcp`
proxying to an already-running daemon), `node` v24.13.0

No Figma interaction was sent. Per-session token cost inside a real agent
session is measured separately with `bench/agent.ts`.

## Startup time (spawn to a successful `tools/list`)

Method: spawn the server over stdio, run `initialize`,
`notifications/initialized`, then `tools/list`, and time spawn to response
with `process.hrtime.bigint()`. N=5 per target.

| Target | N | Median ms | Min ms | Max ms | Note |
|---|---|---|---|---|---|
| turbofig | 5 | 65.8 | 61.1 | 104.0 | daemon already running, as it is by design |
| figma-console-mcp (npx, warm) | 5 | 1859.7 | 1744.9 | 2191.7 | npm package already in the local cache |
| figma-console-mcp (npx, cold) | 1 | 29037.2 | - | - | first run; excluded from the N=5 median |

## Tool-definition size (exact bytes)

`Buffer.byteLength(JSON.stringify(result.tools), 'utf8')` from the same
`tools/list` response. Exact bytes, no token estimate.

| Target | Tools | Tool definitions (bytes) | Bytes per tool |
|---|---|---|---|
| turbofig | 4 | 2,824 | 706.0 |
| figma-console-mcp (default NPX mode) | 121 | 163,208 | 1,348.8 |

figma-console-mcp's docs state 96 tools in Cloud Mode and a smaller
read-only subset over Remote SSE. Only the default NPX mode was measured.

## Reproduce

```sh
node bench/mcp-stdio-probe.mjs turbofig mcp -- --timeout-ms 15000
node bench/mcp-stdio-probe.mjs npx -y figma-console-mcp@latest -- --env FIGMA_ACCESS_TOKEN=figd_dummy --timeout-ms 45000
```

`figd_dummy` is a placeholder, not a real token: figma-console-mcp lists its
tools without a valid one.

Raw per-run data: `session-cost-20261007-144824.json` in this directory.
