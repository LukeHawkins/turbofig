# Hosted-option tool size: figma-console-mcp Cloud Mode and Figma for Agents

Date: 2026-10-07T21:03:48Z

Fills the two hosted "?" cells in the README comparison table. Both hosted
options are reached over the network, never started locally, so "Ready when
your AI starts" is reported as "Hosted, no local start" for both, with no
number.

## figma-console-mcp Cloud Mode

**Earlier attempt:** `cloud-mode-20261007-203749.md` tried to reach
`tools/list` on the live Cloud Mode endpoint with a dummy PAT and was
blocked at 401 before `tools/list`, confirmed again here: the endpoint
checks the PAT before any JSON-RPC method, so no live measurement is
possible without a real, paired Figma account.

**This task:** check whether the upstream README names which tools Cloud
Mode exposes, so the already-dumped NPX tool list could be filtered by
name instead of estimated.

Source: `https://raw.githubusercontent.com/southleft/figma-console-mcp/main/README.md`,
fetched 2026-10-07.

The README states Cloud Mode has 96 of 121 tools, and tags most tool-doc
sections `(Local Mode + Cloud Mode)` or `(Local Mode only)`. Reconciling
every explicit tag against the stated exclusion count (121 - 96 = 25 tools)
only accounts for 14-18 tools:

- Real-Time Awareness, tagged `(Local Mode only)`: `figma_get_selection`, `figma_get_design_changes` (2)
- `figma_get_design_system_summary` / `figma_get_token_values`, tagged `(Local Mode only)` (2)
- `figma_execute_across_files`, tagged `(Local Mode only)` (1)
- `figma_search_components` / `figma_get_component_details`, tagged `(Local Mode only)` (2)
- The `figma_ds_*` group, section tagged `(Local Mode only)` (7)
- Console Debugging (`figma_get_console_logs`, `figma_watch_console`,
  `figma_clear_console`, `figma_reload_plugin`): the capability table's
  "Real-time monitoring (console, selection)" row implies these are
  excluded too, but the per-tool doc does not tag the section (4,
  uncertain)

That is 14 confident exclusions, or 18 with the uncertain Console
Debugging group. Neither reconciles to the stated 25. The remaining 7 to
11 tools cannot be attributed to specific names with confidence, so the
README does not name the Cloud Mode tool set precisely enough to filter
the NPX dump by tool name.

**Method used: proportional estimate**, as instructed for this case.
`96/121` of the already-measured NPX figures
(`tool-tokens-20261007-221725.md`, same NPX dump, same day):

| Metric | NPX (121 tools, measured) | Cloud Mode (96 tools, est.) |
|---|---|---|
| Bytes | 163,208 | 129,487 est. |
| Approx tokens (o200k_base) | 36,569 | 29,013 est. |
| Approx tokens (cl100k_base) | 35,848 | 28,441 est. |
| Share of 200K context (o200k) | 18.3% | 14.5% est. |

Labelled "est." throughout: this is a proportional scale of the measured
NPX tool list, not a direct measurement of the Cloud Mode `tools/list`
response, which stays unreachable without a real Figma PAT.

**Ready time:** Hosted, no local start. No number: there is no local
process to time, and the live endpoint could not be reached past
authentication to measure `tools/list` latency.

## Figma for Agents (Figma's own Dev Mode MCP server)

Source: `https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/`
(fetched 2026-10-07 via a text-rendering proxy, since the page is
JS-rendered), cross-checked against
`https://github.com/figma/mcp-server-guide` (which points to the same
developer-docs page as the canonical tool list).

The docs publish a name, a one-line description, a workflow group, and
(for most tools) a parameters list and a returns description, for every
tool. Names and parameters only, no full JSON Schema types, so the built
JSON below is an **approximation** of a real `tools/list` response, not an
exact one.

**Tool count: 36**, across 7 groups:

| Group | Tools |
|---|---|
| Design to code | 7 |
| Code to design | 5 |
| Image generation | 1 |
| Design systems and Code Connect | 5 |
| Generative plugins and shaders | 9 |
| Account | 1 |
| Weave tools | 6 |

Plus one MCP prompt (`create_design_system_rules`), not counted as a tool.

**Method:** built an approximate JSON array
(`hosted-tool-size-20261007-210348-figma-for-agents-tools.json`) with one
object per tool: `name`, `description` (from the docs' own "what it does"
summary), `group`, and `parameters` (the documented parameter names, with
short notes for optional/typed ones). Counted tokens of
`JSON.stringify(...)` the same way as `tool-tokens-20261007-221725.md`:
js-tiktoken 1.0.21, `o200k_base` and `cl100k_base`, installed into a
throwaway scratch directory.

| Metric | Value |
|---|---|
| Tools | 36 |
| Bytes | 6,262 |
| Approx tokens (o200k_base) | 1,366 |
| Approx tokens (cl100k_base) | 1,352 |
| Share of 200K context (o200k) | 0.68% |

Labelled "est. from published docs": the real tool schemas carry full JSON
Schema parameter types Figma does not publish, so the true `tools/list`
payload is somewhat larger than this approximation, in an unknown amount.

**Ready time:** Hosted, no local start. No number, for the same reason as
Cloud Mode: no local process to time.
